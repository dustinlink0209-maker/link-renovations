# Security Policy

## Reporting a Vulnerability

If you believe you've found a security issue with the Link Renovations website
(linkrenovations.com), please report it privately rather than opening a public
GitHub issue.

**Contact:** nick@linkrenovations.com

Please include:

- A description of the issue and its potential impact
- Steps to reproduce
- Any proof-of-concept (URL, payload, screenshots) — keep it benign

We aim to acknowledge reports within 5 business days. We appreciate responsible
disclosure and will credit reporters who request it once a fix is in place.

## Scope

In scope:

- linkrenovations.com (production)
- qc.linkrenovations.com (staging)

Out of scope:

- Social engineering of staff
- Physical attacks on premises
- Denial-of-service or volumetric testing
- Findings against the underlying Cloudflare or Web3Forms infrastructure
  (please report those directly to the respective vendors)

## Supported Versions

The site is a single rolling deployment. The current production version is
always the supported version.
